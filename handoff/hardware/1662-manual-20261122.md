Three physical Model 12 USB STORAGE cycles were exercised in one Windows desktop process using the local packed-I24 ASIO integration (`f561a57a`, including #1662 `8fd15068` and #1634 `a89e9a4e`). Each card was safely ejected. No manual reconnect was used.

**Diagnostic only.** The Windows default playback endpoint changed while in STORAGE and CPU peaked at 76.6%, above the predeclared 75% gate. The run cannot count as hardware acceptance.

Before STORAGE the 48 kHz / 256-sample duplex stream delivered 375 callbacks in a two-second window around A4. Input 9 measured +5.478 ms against the DIN time reference. After each exit the MIDI capture still received all 960 quarter-frames. The same two-second windows contained only eight callbacks each, with median gaps of 251.285, 251.356 and 251.442 ms respectively. There was no measurable returned A4 in those windows. The ≤3 ms post-recovery comparison remains unverified. This observation does not establish the cause or ownership on the original PR head.
