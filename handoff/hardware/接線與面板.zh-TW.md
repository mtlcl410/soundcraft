# Model 12 實機驗收接線與面板（韌體 1.50 0103）

```text
電腦 ──USB── Roland UM-ONE
             印「TO MIDI IN」 的插頭 ──→ Model 12 背面 MIDI IN
             印「TO MIDI OUT」的插頭 ←── Model 12 背面 MIDI OUT
電腦 ←─USB─→ Model 12
音訊：電腦 USB OUT 1/2 → Model 12 CH9/10（PC）→ 多軌 USB 回電腦
現有：麥克風 → CH1 LIVE；PC1X L → CH2 LIVE；MAIN L/R → 喇叭
```

**初始面板（約 2 分鐘）**　本體停在錄音機的 48/24 測試歌曲。按 MENU、用 MULTI JOG 選取並按下確認。在 SYSTEM → USB AUDIO，將「PC ←」設 MULTI INPUT，「PC CH1/2 →」設 TO CH9/10。在 SYSTEM → OUTPUT DELAY → DELAY 選 DISABLE。CH9/10 的 MODE 選 PC，監聽低音量。MENU → MIDI 的 MIDI TIMECODE 和 MIDI CLOCK/SPP 都選 OFF。電腦會先以低電平脈衝確認哪一對 USB 輸入實際有回送，軟體輸入監聽關閉。正式量測期間使用本機桌面，關閉遠端桌面連線。

**集中面板操作**　腳本就緒後才開始。三次播放及十分鐘錄音本身合計 13 分 30 秒，連同選單、寫卡與安全退出，建議預留 20～25 分鐘。

1. **M-3，約 11 分鐘。** 用空白的 48/24 歌，將 MIDI TIMECODE 和 MIDI CLOCK/SPP 設為 OFF。選 CH9/10 的 REC 待命，按走帶區 ●，確認計數前進後通知電腦開始送標記。收到通知後按 ■，等 SD 寫完，記下歌曲名。
2. **H-4b，約 4 分鐘。** 留在剛錄好的歌曲；解除 CH9/10 的 REC 待命，MODE 維持 PC。停止中將 MENU → MIDI → MIDI TIMECODE 設 ON。回歌頭按 ▶，70 秒後按 ■；回歌頭重複一次。第三次以 MULTI JOG 定位到約 00:00:30，按 ▶，70 秒後按 ■。每次停止至少 3 秒。最後將 MIDI TIMECODE 設回 OFF。
3. **H-3b，約 2～4 分鐘。** 依自動量測提示進 MENU → STORAGE → F4（YES）；Windows 安全退出 SD 後才以本體 EXIT 回到歌曲畫面。每輪保留約 20 秒供重連及量測，共三輪。
4. **H-7，選做。** 依提示將「TO MIDI IN」移至 PC1X MIDI IN，由電腦送音及 Stop 共 20 次；結束後接回 Model 12 MIDI IN。
5. **H-5，選做。** 在指定穩速區間拔插一次 UM-ONE USB，電腦比對軟體停用與實際斷線。
