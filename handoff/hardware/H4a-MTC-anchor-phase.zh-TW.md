# H-4a　停止中定位後的 MTC 起音極差

在 48 kHz／256 取樣的同一批輸入上，#1663 舊版十組 PCM 起音極差全部超過 3 ms。本機修正後，十組均在 1.196–1.813 ms。這是實錄時間戳的離線重播。原驗收的實體 USB 回錄仍保留，硬體是否也達標要用相同接線重測。

## 重現與修正

固定同一段 30 fps 線上 MTC，僅把規律的 256 取樣回呼平移 0 至 255 個取樣。在舊版，確認鎖定後的定位點首音落在接手該事件的回呼起點，極差 5.313 ms。本機修正以鎖定時間戳計算緩衝內的起音取樣位置，前段繼續處理停止狀態的監聽，後段從定位點正常播放。相同掃描的極差降到 0.001 ms（時間以整微秒記錄）。

每次均掃描實際渲染的立體聲 PCM，放置定位點首音、後續標記和半秒處標記。非零定位另在前方放置一音。100 段均只有三次起音，首尾間隔全為 24,000 取樣。[修正前失敗紀錄](runs/asio-idle-archive-recheck/h4a-matrix-red.log) · [修正後逐段結果](runs/asio-idle-archive-recheck/h4a-matrix-candidate.log)

## 新量到的大緩衝代價

用理想 30 fps 時碼，以 225.000 ms 為同一組時碼收齊的時刻。下表逐緩衝平移八種回呼相位，從渲染的 PCM 中找定位點首音。這段時間從確認鎖定起算，另有等待 MTC 鎖定及裝置輸出的時間。

| 緩衝（取樣） | 確認鎖定至首音 | 八次極差 |
|---|---:|---:|
| 128 | 2.666–2.667 ms | 0.001 ms |
| 256 | 5.333 ms | 0 ms |
| 512 | 10.666–10.667 ms | 0.001 ms |
| 2048 | 42.666–42.667 ms | 0.001 ms |

2048 取樣時，穩定的首音仍在鎖定後約 42.67 ms 才出現。這是候選策略的實際代價；3 ms 是重複性門檻，不能用它推論反應夠快。本輪沒有設定或變更絕對起播延遲的驗收值。[逐緩衝 PCM 紀錄](runs/asio-idle-archive-recheck/anchor-buffer-sweep.log)

## 仍須分開驗收的門檻

- **音訊往返 M-1**　1 取樣極差門檻仍超標。獨立播放器在 128、256、512 緩衝的實機極差為 5、6、11 取樣，整合版為 5、4、6 取樣。兩種播放器皆有變動；目前無法歸因於單一 PR。
- **ASIO 串流恢復 H-3**　退出 STORAGE 後舊串流持續約 251 ms，獨立播放器也能重現。重建後約 5.33 ms。main 的自動恢復候選仍待三次真實 STORAGE 操作。[恢復驗收](ASIO-storage-idle-recovery.zh-TW.md)
- **#1662**　H-1 的 tick 計數及排程 p99／最大值、H-2 的聲音對 Clock 校準殘差、H-3 的裝置失效及恢復警告，各有實機門檻。此次播放模組測試未提供這些項目的新實機數值。
- **#1663**　H-4a 硬體重測應同時量起音極差及絕對延遲，分列 ASIO 輸出、USB 回送。先前 H-4b 的三次實機起音極差為 1.791 ms，回送端首音仍晚約 216–218 ms。大幅重新定位可能跳過完全落在跨越區間內的短音；本次測試驗證停止中定位後的首音。
- **#1669**　H-5 的逐八分音符偏差、漏音及誤判斷鐘，H-6 的 MIDI 與錄音差，H-7 的外部琴收音，H-9 的狀態燈仍依原驗收條件。H-8 需端到端分段量測，H-10 需雙向實體埠連續兩小時。本輪數據不足以宣告這些項目通過。
