## Goal

Give musicians three ways to synchronize a SoundCraft session with external MIDI gear. A sequencer or drum machine should follow the session tempo and transport. A timecode device should be able to follow SoundCraft, or lead it when SoundCraft is online. A clock master, such as a sequencer or sampler played live, should be able to lead SoundCraft's tempo and transport.

The settings follow the Pro Tools model (Reference Guide 2026.4): device latency is set per MIDI port in samples and stored with the machine; timecode position (session start, external offset, timecode rate) is stored with the session.

## Plan

1. **#1662 — MIDI Beat Clock output** and the shared sync layer.
   - Setup › MIDI › MIDI Beat Clock: enable, choose one or more output ports, a signed sample offset per port.
   - 24 clocks per quarter note; Start from zero; Song Position Pointer and Continue elsewhere, aligned to the next sixteenth.
   - Shared layer used by every sync feature: one "heard position" from the audio clock, per-port device offsets, optional delay compensation for generated MTC / Beat Clock / MIDI notes, a timestamped MIDI send path, and `setup.midi_sync_status` diagnostics.
2. **#1663 — MIDI Time Code generation and chase.**
   - MTC Reader/Generator ports in Setup › Peripherals › Synchronization; a Gen MTC transport toggle; session start (default 01:00:00:00 for new sessions), timecode rate and external offset in the session.
   - Full-frame on stopped locates, quarter frames while rolling, at 23.976, 24, 25, 29.97 non-drop/drop-frame and 30 fps.
   - Chase: lock, locate to the incoming timecode, then run on SoundCraft's own sample clock, re-locating if it drifts; Freewheel (4–40 frames, default 8) or Jam Sync on dropouts.
3. **New PR — follow an external MIDI Beat Clock.**
   - Tempo estimated from incoming clocks; Start, Continue, Stop and Song Position Pointer followed; keep running or stop when the clock disappears.
   - No audio resampling: the followed tempo drives SoundCraft's transport.
   - Also lets users join other ecosystems through third-party bridges that convert them to MIDI clock (SoundCraft does not include any of that code).

## Acceptance

- [ ] Beat Clock: clocks, Start/Stop/Continue and SPP verified with simulated-time tests (steady and changing tempo, off-grid starts, bursty audio callbacks, CPU load), each proven to fail without its fix.
- [ ] MTC: quarter-frame order and timing at every supported rate, drop-frame minute and ten-minute boundaries, locate accuracy including output latency, freewheel and Jam Sync, verified with simulated-time tests.
- [ ] Clock follow: lock time, tempo error and phase error bounds under timestamp jitter, tempo steps and dropouts, verified with simulated-time tests.
- [ ] Hardware check once all three are in their final form: end-to-end Beat Clock and MTC timing on the wire, MTC chase from a hardware recorder (with the recorder as the audio interface, so both share one clock, and with a separate interface), clock follow from a hardware clock master, and the same runs under a heavy session. Results go into the PR descriptions with the diagnostics output.
