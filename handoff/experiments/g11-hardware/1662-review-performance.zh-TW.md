# G-11 MIDI Beat Clock 審查後的 Windows 效能驗收

2026-11-20。基準版本為 #1662 原始 head c9dab9e。兩版在同一台 Windows 主機使用 Cargo 最佳化測試組態，節奏固定，模擬音訊回呼每 10 ms 發布一次位置，接收端在工作執行緒送出 F8 處以單調時間戳記錄。

| 指標（三輪中位數） | 120 BPM 原版 | 120 BPM 修正版 | 180 BPM 原版 | 180 BPM 修正版 |
| --- | ---: | ---: | ---: | ---: |
| 脈衝間隔標準差（ms） | 1.440 | 0.452 | 1.449 | 0.272 |
| 絕對間隔誤差 P95（ms） | 2.717 | 0.799 | 2.859 | 0.405 |
| 五秒內工作迴圈次數 | 2755 | 537 | 2767 | 725 |
| 五秒內工作執行緒 CPU cycles（百萬） | 171.2 | 45.6 | 159.1 | 60.2 |

每組測五秒，輪換先後順序。排除啟動後前兩個間隔，以 60,000 / BPM / 24 毫秒作為理想值。CPU cycles 獨立執行三輪，以 Windows QueryThreadCycleTime 讀取各工作執行緒累計值。

另以空專案、48 kHz、64-frame 緩衝區量測回呼。每輪預熱 1000 次，再量 200 批、每批 100 次，四輪交錯開關 Beat Clock。關閉與開啟的中位數分別為 1.758 與 1.792 微秒。讀取端持有快照時，回呼仍可立即返回，下一個回呼重試，此行為另有功能測試。

舊版實體資料來自 Model 12 → UM-ONE 的 Windows 回錄。120 BPM 兩次分別有 169、63 個脈衝，間隔標準差 1.296、1.640 ms。修正版數值在工作執行緒輸出端取得。這輪僅列舉到 UM-ONE，修正版的 USB、DIN 及裝置端抖動，以及有負載的大型專案和其他作業系統仍未量測。

原始資料為本目錄的 review-final-bench.log、review-worker-cpu-bench.log、review-final-worker-cpu.json、beat-review-probes-red.log 和 wire.jsonl。
