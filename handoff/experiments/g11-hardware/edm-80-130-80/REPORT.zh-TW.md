# 電子舞曲合奏 · 80 → 130 → 80 BPM

12 小節、4/4 拍，各段 4 小節。第 5 小節（12.000 秒）直接加速到 130 BPM，第 9 小節（19.3846 秒）直接降回 80 BPM，全曲 31.3846 秒。兩處都在播放中換速。成品包含四拍底鼓、反拍小鼓、八分音符踩鈸、切分貝斯，以及在兩個轉段起點各一聲的銅鈸。[可開啟的 SoundCraft 專案](<EDM 80-130-80.scraft>) · [修正後合奏試聽](EDM-80-130-80.mp3)

## 訊號路徑及判讀

一個 SoundCraft 程序讀取歌曲速度軌、彈奏鼓聲並發出 MIDI Clock。另一個程序的專案只有 80 BPM，經 Model 12 USB MIDI → DIN OUT → Roland UM‑ONE 跟隨前者。從歌頭只送一次 Start，結尾送 Stop。兩個程序的聲音分占同一個 48 kHz S/PDIF 數位回錄的左右聲道。每版先以底鼓與踩鈸跑三遍作校準，再以完整安排錄一遍。試聽 MP3 取自完整合奏的實錄，將左右聲道略混合以便聆聽；原始 WAV 保留兩個程序的聲道。

用各打擊樂的實際取樣在整段回錄搜尋起音。校準的正規化相關係數門檻為 0.85；另以相鄰預期起音的中點劃分，檢查每個八分音符位置恰好有一次。完整編曲另辨認反拍小鼓及兩次轉段銅鈸。拍點表列跟隨端減主奏端，扣除變速前七拍的中位偏差；正值為較晚。加速與減速各自用前一段作基準。這項比較量的是兩個定序器在同一數位輸出上的相對時間。

## 實測數據

完整舞曲在實體 MIDI 線上量到 80.003、129.996、80.000 BPM，只有一次 Start 和一次 Stop，跟隨端正常停止。完整混音辨認到 24 個單獨底鼓正拍、24 個帶小鼓的正拍、96 下踩鈸及兩聲轉段銅鈸。[完整混音檢查](final/full-mix-analysis.json) · [原始 WAV](final/mix-1.wav)

| 同一遍錄音中的拍點 | 修正前，三遍 | 修正後，三遍 |
| --- | ---: | ---: |
| 80 → 130，變速後第一個反拍 | 晚 54.5–59.6 ms | 晚 21.4–29.3 ms |
| 80 → 130，下一個正拍 | 晚 47.7–52.7 ms | 晚 5.4–6.2 ms |
| 130 → 80，變速後第一個反拍 | 早 122.4–133.9 ms | 早 101.9–126.1 ms |
| 130 → 80，下一個正拍 | 早 113.1–127.7 ms | 早 25.8–37.2 ms |

每次校準錄音均收到 48 下底鼓與 96 下踩鈸，三段各有 16 下底鼓、32 下踩鈸，每個位置恰有一次起音。最後一段末四拍的中位偏差在修正後距離前段基準 3.5–6.6 ms。快速段切回 80 BPM 的第一下反拍仍有超過 100 ms 的提早量，之後的正拍改善較大。

中間版本雖通過理想時鐘回歸，但有兩遍降速後下一拍仍早 140–155 ms，未採用。最終版在音訊已經算到 MIDI Clock 前方時，允許從仍能更動的位置再次修正速度。下一拍在三遍中都改善。[逐遍比較含中間版本](comparison.json) · [最後版本分軌 WAV](final/cal-1.wav) · [前後對照圖](../../g11-storage-clock-follow/docs/images/midi-clock-edm-tempo.png)

## 軟體驗證

舊版在完全無抖動的 80 → 130 BPM 測試中，把變速後下一拍排晚 1,862 個取樣（48 kHz，38.79 ms），超過 130 BPM 的一個 MIDI Clock（19.23 ms）。修正後，在輸入端確認速度突變後的一拍內，才以較快的速度校正拍點；校正從仍可更改的取樣位置算起。這次共測 80 ↔ 130、100 ↔ 120 四種方向，核對下一拍誤差在一個 Clock 內，以及已經播過的小節起點仍在原位。實體迴路的偏差另見上表。
