# A-1 連續推速的 PCM 驗收

音源為時間確定、長度 96 個取樣的 sampler。取樣率 48 kHz，最多每 128 個取樣渲染一次；每筆 F8 到達前都先渲染已經過的區段。比較實際左聲道 PCM 每次起音相對來源拍點的帶正負號差值，正值為晚。逐音比對完整波形，最後一音後再讀一秒，檢查是否多出起音。

從 124 BPM 在 32 小節內線性推到 133.92 或 114.08，再用 32 小節返回。慢漂移以 16 + 16 小節測 124.0 → 124.3 → 124.0。每項各跑理想時脈、均勻 ±1 ms 和 ±2 ms 的獨立到達抖動。同一批 F8 與音符用於修正前後和候選方案。抖動種子為 42。

| 速度行程 | 抖動 (ms) | 紅測最大絕對偏差 (ms) | 修正後最大絕對偏差 (ms) | 每輪核對起音 |
|---|---:|---:|---:|---:|
| +8% | 0 / 1 / 2 | 7.7292 / 7.8750 / 7.9375 | 2.3542 / 2.4375 / 3.8333 | 513 |
| −8% | 0 / 1 / 2 | 8.9792 / 8.8542 / 9.0625 | 2.7708 / 2.9167 / 3.7500 | 513 |
| +0.3 BPM | 0 / 1 / 2 | 3.1042 / 3.0625 / 3.7917 | 3.1042 / 3.0625 / 3.7917 | 257 |

最大的舊版偏差出現在 −8%、±2 ms 的第 246 個起音，早 435 個取樣（9.0625 ms）。在這一輪，192 個 pulse 的線性擬合速度與已知速度最多差 0.33424 BPM，擬合時間戳誤差最多 2.35588 ms。保留這兩個估計的結果，只在持續推速時縮短相位追蹤的反應、減少更新門檻，PCM 峰值降到 3.7500 ms。單一速度擬合的落後與原設定的相位平滑共同影響起音。

最終採用時間戳二次項的投影判斷趨勢；相對變化大於每秒 0.045%，且投影超過三個估計標準誤，才縮短相位追趕。仍採用線性擬合的 BPM 與脈衝位置供顯示和排程。在 124.0 → 124.3 → 124.0 的三輪中，大幅變速誤觸和連續推速模式誤觸都是 0。九輪都沒有漏音、重音或截尾。排除起播估速的一拍後，最大相鄰 BPM 顯示輸入變化為 0.09139。

| 比較過的方案 | ±8% 六輪最大絕對偏差 | 觀察 |
|---|---:|---|
| 加快三段時間窗偵測，4 標準誤 | 4.7292 ms | 超過目標 |
| 三段時間窗，3 標準誤 | 3.8333 ms | 慢漂移 ±2 ms 有 5 個 pulse 進入推速模式 |
| 二次項外推時間戳和速度，初版 | 5.6875 ms | 輸入抖動放大 |
| 一律快速更新網格 | 3.1875 ms | 穩定與慢漂移時仍持續採用快速更新 |
| 最終採用二次投影偵測，保留原估計 | 3.8333 ms | 慢漂移均未啟用推速模式 |

九組穩速的 BPM 與相位 p95 逐項與 af4af80 基準相符，通過 90/120/174 BPM × 0.5/2/4 ms 高斯及 1 ms 量化，其中每組從第一拍後都沒有誤入推速模式。12 組理想時脈大幅變速的逐音結果與原測試相符。原有八小時 ±0.2 BPM 網格測試處理 1,382,400 筆 F8，峰值 148 個取樣；此處的八小時數據是既有網格測試，整合版的完整八小時 PCM 另由總報告記錄。
