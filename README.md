# SoundCraft issue evidence (2026-11-26)

This branch holds the evidence files cited by issues filed on
[storytold/soundcraft](https://github.com/storytold/soundcraft). It is not code and is not meant
to be merged; it has no history in common with `main`.

Layout: one folder per issue, `issues/<draft-number>-<slug>/`. Each issue body links the files in
its folder.

- Screenshots are of the SoundCraft window only (1600 x 932 window captures, macOS 26.1); no
  desktop, menu bar, Dock or other applications.
- Logs are short excerpts from the test scripts (command replies, positions, timings). They contain
  no machine names or personal paths.
- Pro Tools Reference Guide pages are cited by page number in the issues and are not copied here.
- Evidence seen only on the Windows test machine is described in words in the issue and is not
  included here.
